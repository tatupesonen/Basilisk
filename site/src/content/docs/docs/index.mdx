Basilisk is a reimplementation of [Ghidra](https://github.com/NationalSecurityAgency/ghidra) in Rust:
loaders, SLEIGH, p-code, analysis, the decompiler and a desktop interface. These pages explain how to use it
and how it works inside.

<Callout kind="caution" title="Early development">
Basilisk cannot open a real program yet. What works today is the language layer: it disassembles bytes and
lifts them to p-code for every processor Ghidra ships, and it compiles SLEIGH specifications to the same
bytes as Ghidra's compiler. The desktop interface runs on a built-in demo program. The decompiler is being
ported now. Every page says what exists today and what is planned. The [status matrix](/status/) and the
[roadmap](/roadmap/) are generated from the project's own records.
</Callout>
