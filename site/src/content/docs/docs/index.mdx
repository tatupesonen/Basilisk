Basilisk is a reimplementation of [Ghidra](https://github.com/NationalSecurityAgency/ghidra) in Rust:
loaders, SLEIGH, p-code, analysis, the decompiler and a desktop interface. These pages explain how to use it
and how it works inside.

<Callout kind="caution" title="Early development">
Basilisk cannot open a real program yet. The desktop interface runs on a built-in demo program, and the
foundations — Ghidra's language files, SLEIGH, p-code — are being built first. Every page says what exists
today and what is planned. The [status matrix](/status/) and the [roadmap](/roadmap/) are generated from the
project's own records.
</Callout>
